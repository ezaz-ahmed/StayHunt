# Legacy Application

This directory/repository history contains the original application developed over several years.

The application is being rebuilt from the ground up with a new architecture based on:

- Turborepo
- Next.js
- Hono
- PostgreSQL
- Drizzle ORM

The legacy implementation is preserved in Git history and under the `legacy-v1` branch/tag.

The rewrite is an opportunity to establish clearer architecture, stronger type safety, testing, separation of concerns, and maintainability.
